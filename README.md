# API Docs Dictionary

API 文档路径字典，收录主要 HTTP API 框架及插件的文档页面、OpenAPI / Swagger 规范端点和常见自定义路径。

[下载字典](api-docs-paths.txt)

- 共 181 条，每行一个路径。
- 按区分大小写的字典序排列，已去重并移除开头的 `/`。
- 使用 UTF-8 无 BOM 编码和 LF 换行，可直接导入支持文本字典的工具。
- 保留尾部 `/` 和查询参数，使用时将路径拼接到目标应用的基础 URL 后。

路径会随框架版本、插件配置和部署前缀变化，实际可用地址以项目配置为准。
